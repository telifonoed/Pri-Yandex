# Pri-Yandex

### Privacy, not profiling.

---

## Что это?

Pri-Yandex — небольшой приватный браузер на настоящем движке Chromium
(QtWebEngine — Blink + V8). Не «обёртка над Chrome», а самостоятельная программа
со своим окном, вкладками, адресной строкой и панелью «что заблокировано».

Слой приватности делает то, что браузер должен делать по умолчанию:

- **Никакой телеметрии.** Нет синхронизации, фоновых отправок, профилирования.
- **Блокировка трекеров** — правила в стиле EasyList, включая собственные
  `metrica`, `webvisor` и `appmetrica` Яндекса.
- **Очистка URL** — `utm_*`, `fbclid`, `gclid`, `msclkid`, `yclid` и ещё ~40
  трекинговых параметров вырезаются при каждом переходе.
- **Срез заголовков** — `Referer` удаляется, отправляются `DNT: 1` и `Sec-GPC: 1`.
- **Рандомизация отпечатка** при каждой загрузке страницы — WebGL, canvas,
  аудио, шрифты, профиль оборудования.
- **Блокировка рекламы** — ~90 рекламных сетей в отдельном списке.
- **Cookies под контролем** — сторонние отбрасываются; есть полная блокировка.
- **~110 доменов трекеров** и **~90 рекламных сетей** в списках в стиле EasyList, которые можно расширять.
- **Ничего не пишется на диск C.** Профиль, кэш, temp, загрузки и настройки
  лежат рядом с программой.

> **Pri** = *Privacy*. Форк Яндекс Браузера в **обратную** сторону:
> та же основа Chromium, ноль слежки.

## Быстрый старт

```bash
git clone https://github.com/YOUR_USER/Pri-Yandex.git
cd Pri-Yandex
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe run.py
```

### Готовая сборка

Скачай `Pri-Yandex.exe` из раздела Releases (~249 МБ — Python, Chromium и все
ресурсы внутри). Запуск двойным кликом.

## Встроенные страницы

| Страница | Что делает |
|---|---|
| `pri://newtab` | Стартовая — поиск, ярлыки, логотип |
| `pri://settings` | Все настройки (внешний вид, поиск, защита, приватность) |
| `pri://blocked` | Всё, что Pri не пустил, сгруппированное по причинам |
| `pri://about` | Версия и активные настройки |

## Настройки

**Внешний вид** — светлая/тёмная тема, домашняя страница.
**Поиск** — DuckDuckGo, Google, Yandex, Brave или свой шаблон.
**Защита** — блокировка трекеров, блокировка рекламы, скрипты третьих сторон,
скрытие cookie-баннеров, работа с cookie, очистка URL, блокировка
speculative-навигации.
**Конфиденциальность и безопасность** — DNT, GPC, антифингерпринт, разрешения
(отказ по умолчанию), политика WebRTC, Safe Browsing, DNS-prefetch.

Всё сохраняется в `userdata/config.json`.

## Как это устроено

Вся приватность обеспечивается на сетевом уровне:
`QWebEngineUrlRequestInterceptor`, установленный на профиль. Каждый запрос
проверяется до того, как покинет браузер: сверяется с доменными правилами,
очищается от трекинговых заголовков или блокируется полностью.

Антифингерпринтинг — JavaScript, внедряемый при `DocumentCreation` в main world,
поэтому он выполняется раньше любого скрипта страницы и подменяет реальные
значения до того, как их успеют прочитать.

## Честные ограничения

- **Это не Tor.** IP-адрес сайтам по-прежнему виден. Для анонимизации нужен VPN
  или Tor.
- **Только доменная блокировка.** Нет косметической фильтрации и блокировки
  скриптов уровня uBlock. Реклама, отдаваемая с самого домена сайта, не
  заблокируется.
- **Основа — Chromium.** Движок написан Google. Pri убирает телеметрию и
  синхронизацию, но фундамент остаётся.
- **Часть сайтов ломается** при агрессивной блокировке (Яндекс, Ozon,
  маркетплейсы). Добавляй их в allowlist.

## Требования

- Windows (проверено на Windows 10/11)
- Python 3.10+ (разрабатывалось на 3.14)
- PySide6 6.12
